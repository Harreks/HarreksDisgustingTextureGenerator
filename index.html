Usage

This is a texture generator to make Harrek's Disgusting Buff Tracker work. You need the addon installed and the icons inside your '/Interface/Icons' folder for it to work.
  1. Pick the spec you want to make icons for at the top.
  2. Select where each available buff will go on the frame. Use the preview to help you visualize it.
  3. Once you are done with your set up, click 'Save Textures', this will download a .zip with all your new icons.
  4. Put these files inside 'World of Warcraft/Interface/Icons/'. If the folder doesn't exist you can just make it.

F.A.Q.

Can i have icons for multiple specs at once?

You can have all the icons in your wow folder at the same time and it will work, but you need to create them spec by spec here. Changing between specs will reset everything so just do one at a time.

Why only six slots?

It seemed like a reasonable number to offer a bit of customization without going overboard. Basically i felt like six.

Why only these spells? can i add x?

No. The list comes from Blizzard i am simply replacing the icons and sticking them in your frames, i can't do anything to add or remove spells from the list.

Can i replace only some of the spells?

No. The method requires all icons to be either colored squares or fully transparent, any icon not replaced would result in a huge square covering half the frame. Icons that you don't select a section for will simply be invisible everywhere.

Is there a way to do the icon tracking but keep the icons working on action bars/talent tree/cooldown manager?

Not that i am aware of.

Is this vibe coded?

Yea a good part of it. This really is a disgusting solution (hence the name) and i wanted to avoid spending time on it as much as possible.

But does it work well?

Yea it works, i haven't done super extensive testing but i got it running on dungeons and i don't see why it would break in a raid. You won't find the most clean and efficient code ever here but if you have played wow for long enough im sure you have used worse addons before performance-wise. If you do find a bug feel free to send it my way.
